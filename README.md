# SITARAM EVENT

**Creating Royal Memories, Making Every Celebration Extraordinary.**

Royal luxury event planning and management serving Bildi (Biladi), Mahuva and Surat, Gujarat.

## Project
- Responsive bilingual (English/Gujarati) public website
- Black and metallic-gold royal luxury visual identity
- HTML, CSS and vanilla JavaScript
- Supabase backend planned for PostgreSQL, Auth and Storage
- Hosted on GitHub Pages

## Current status
Phase 1 scaffold: public website foundation. Supabase credentials and database policies will be configured in a later phase.

## Local preview
Open `index.html` in a browser, or serve this folder with any static web server.

## Configuration
Update `assets/js/config.js` with the Supabase project URL and publishable/anon key when the Supabase project is ready. Never place a service-role key in frontend code.
